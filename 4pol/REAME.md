# Поиск аномальных респондентов в поисковых запросах (SoS)

## Описание

Скрипт реализует алгоритм обнаружения аномально высокой активности респондентов по брендам в данных поисковых запросов.  
Аномалия определяется на уровне `(SubjectID, researchdate, BrandID, CategoryDelivery)`. Если респондент признан аномальным хотя бы по одному бренду в конкретный день, **удаляются все его строки за этот день**.

Алгоритм:
- Фильтрует строки с `BrandinDelivery == 1` и непустой `CategoryNameDelivery`.
- Считает `daily_ots = Weight × количество запросов` для каждой комбинации (респондент, день, бренд, категория).
- Вычисляет порог как **99-й перцентиль** `daily_ots` в группе (день, бренд, категория). Если наблюдений в группе мало (меньше 5), используется глобальный перцентиль по бренду (требуется минимум 20 наблюдений).
- Формирует `anomalies.csv` – список пар `(SubjectID, researchdate)` для удаления, и `anomaly_reasons.csv` – диагностику по каждому бренду-триггеру.
- Строит обязательные графики и аналитические визуализации «до/после» по демографическим признакам, ресурсам и категориям.
